# 阶段 2：数据库设计 Prompt

```text
你现在是资深数据库设计师和后端架构师。请基于当前项目文档，检查并完善心理测评系统的数据库设计。

重点参考：
- doc/04-data-model-design.md
- doc/10-database-table-design.md
- doc/11-database-ddl-draft.sql
- doc/12-database-init-and-seed.sql
- doc/14-erd-design.md

技术约束：
- 数据库使用 PostgreSQL
- 基础认证表来自 auth-starter
- 心理业务表统一使用 psy_ 前缀

你的任务：
1. 审查现有表结构是否足以支撑主业务闭环。
2. 检查表之间的主外键关系、唯一约束、索引设计是否合理。
3. 检查匿名测评、预警闭环、预约咨询、通知提醒是否都有数据承载。
4. 检查字典/枚举表设计是否覆盖所有状态字段。
5. 检查大数据量场景下的索引和分区策略建议。
6. 如有必要，提出字段级修正建议。
7. 输出最终建议版数据库结构说明。

预期产出物：
- 数据库审查结论
- 字段修正建议
- 索引与分区建议
- 最终建议版结构说明

上下文传入方式：
- 必传本 Prompt
- 必传数据库相关文档
- 如阶段 1 已执行，可附模块划分和 MVP 范围摘要

输出要求：
- 优先从业务闭环角度检查
- 明确指出需要改的表和字段
- 尽量给出具体 SQL 或字段建议
```
