# 产品验收测试用例矩阵

## 1. 文档目的

本文档用于给后续开发、测试和验收提供基础检查矩阵，覆盖功能、角色、权限与状态组合。

## 2. 验收范围

- 量表管理
- 测评任务
- 在线答题
- 报告生成
- 预警闭环
- 咨询预约
- 角色权限
- 数据导出

## 4. DoD 建议

一个功能模块达到可验收状态，建议至少满足：

- 主流程可执行
- 异常流程有处理
- 权限校验通过
- 审计日志正确记录
- 关键状态流转正确
- 回归测试通过
