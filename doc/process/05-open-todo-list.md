## 4. 当前建议优先级

如果按“最值得继续做”的顺序推进，建议如下：

1. 更多真实 Push 厂商 SDK / FCM 深度直连
当前进展：已补充 FCM HTTP v1 直连网关、Push 渠道回执和通知点击回执基础闭环，剩余重点转为更多厂商 SDK、移动端路由映射与深链兼容策略。
2. 设备会话治理增强
   当前已完成两层下沉：`auth-starter` 已承接按设备查询最近会话、按设备批量撤销活跃会话、统一设备画像模型、基础自动处置与认证域设备接口收口；剩余重点改为更细粒度租户级 / 用户级风控策略、刷新令牌治理与异常设备处置策略继续增强
3. 对象存储真实 SDK 适配与导出治理增强
4. 更完整的通知策略中心与运维审计能力
5. 常模导入工具与覆盖率校验
6. `MATRIX` 等复杂题型链路收口
