## 3. 可交付但建议补强

以下能力已经可用，但更适合作为“baseline 可交付”，还不是最终产品级收口：

- refresh token 失败后的重登体验仍可更完整
- 会话失效提示和跳转策略仍可更细
- PDF 字体兜底和跨环境稳定性仍可加强
- 群体报告和统计目前以基础看板为主，深度分析还不够
- 预约 / 咨询虽然已有页面和接口，但完整业务闭环仍可继续细化
- 部分测试断言为提高稳定性做过收敛，后续还可继续加细粒度验证

1. 补产品级收口：会话失效 UX、PDF 稳定性、预约 / 咨询闭环细节。
2. 补交付级保障：CI、自动化检查、构建发布脚本。
3. 补分析能力：复杂统计图表、深度群体分析。
4. 再启动多端实现：Android / iOS / 微信小程序。
