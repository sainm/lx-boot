# 过程文档索引

## 1. 保留原则

`doc/process/` 只保留仍然有持续维护价值的文档：

- 当前进度和基线结论
- 国际化等长期规范
- 文档维护规则

已经移除：

- 历史阶段执行日志
- 一次性 Prompt 计划
- 单次交付清单
- 单次工程评审记录

这些内容对当前开发判断帮助有限，而且容易和“当前真实状态”混淆。

## 3. 使用方式

- 想知道项目现在做到了什么：看 `03-current-progress-dashboard.md`
- 想知道当前还有什么没做完：看 `05-open-todo-list.md`
- 想知道什么已经算当前基线：看 `04-baseline-closure.md`
- 想继续补多语言：看 `07-i18n-guide.md`
- 想维护文档而不再堆历史垃圾：看 `08-doc-hygiene-checklist.md`
