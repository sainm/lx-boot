# Baseline 闭环说明

更新时间：2026-04-16

## 1. 当前 baseline 的含义

当前 baseline 不代表“产品已经全部做完”，而代表：

- 主链路可运行
- 代码结构可继续迭代
- 关键功能已有第一版闭环
- 文档与代码状态能够基本对齐

## 2. baseline 内已经包含的内容

### 后端闭环

- 量表配置与版本化
- 测评任务与问卷提交
- 自动评分与系统报告
- 预警、干预、复测任务
- 通知分发、设备登记、投递流水、失败重试
- 导出任务异步化、持久化、自动补跑和重试

### 前端闭环

- 管理端主菜单和权限路由
- 用户侧 Web 主流程
- 通知运维工作台
- 导出中心运维面板

### 工程闭环

- `admin-web` 可构建
- `backend` 核心测试可执行
- i18n 基础设施已经接入

## 3. 当前 baseline 不包含的内容

- Android、iOS、小程序端实现
- 真实 Push 厂商 SDK 接入
- 真实对象存储厂商 SDK 接入
- 完整设备会话治理
- 最终形态的深度统计分析
- 完整 CI/CD 和发布流水线

## 4. 当前 baseline 上仍需继续补强的方向

1. 外部渠道接入
2. 设备会话治理
3. 对象存储生产化
4. 常模工具和复杂题型深水区能力
5. 运维审计和治理能力继续增强
