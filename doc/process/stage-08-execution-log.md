1. 登录或身份绑定
2. 查看我的任务
3. 进入答题
4. 提交后查看报告
5. 查看预约与通知

1. 测评任务提醒
2. 预约提醒
3. 复测提醒

分包策略建议：

1. 主包保留首页、登录、任务
2. 报告、预约、通知可按页面分包
3. 控制包体积，避免引入过重依赖
