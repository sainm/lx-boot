# 阶段执行记录模板

## 1. 用途

后续如果继续按阶段推进新功能、补强项或多端工作，可以复制下面的模板记录一次阶段执行结果。  
这个模板的目标是让过程文档保持可追踪、可复盘、可交接。

## 2. 模板

```text
阶段名称：
执行日期：
负责人：

使用的 Prompt / 参考文档：
- 
- 

输入信息：
- 
- 

本阶段目标：
- 

本阶段输出：
- 
- 

涉及代码 / 文档：
- 
- 

验证结果：
- 
- 

发现的问题：
- 
- 

是否需要回写文档：
- 是 / 否

回写的文档：
- 
- 

是否进入下一阶段：
- 是 / 否

下一阶段准备事项：
- 
- 
```

## 3. 建议最少记录的内容

- 这一阶段到底完成了什么
- 影响了哪些模块
- 跑了什么验证
- 还有什么未解决风险
- 是否修改了文档或交付结论

## 4. 当前建议

对 `lx-boot` 这个仓库，后续最值得持续记录的阶段包括：

- 国际化继续扩展
- 预约与咨询闭环补强
- PDF 与导出能力收口
- 安全与权限回归验证
- CI/CD 与部署收口
- Android / iOS / 微信小程序启动
