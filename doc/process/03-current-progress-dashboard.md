# 当前进度看板

更新时间：2026-08-08

## 1. 总结

当前仓库已经不是“只有设计稿”的阶段，而是进入了可持续迭代的工程基线阶段：

- `admin-web` 可构建
- `backend` 关键测试可运行
- 管理端、用户侧 Web、导出、通知、预警、干预、预约、审计等主链路已形成第一版闭环

但仍然没有达到“所有路线图都彻底完成”的状态。剩余工作主要集中在：

- 真实外部渠道接入
- 上游认证体系联动后的设备风控与短期会话治理继续增强
- 更完整的对象存储厂商适配
- 深水区评分/常模工具和复杂题型收口

## 2. 当前已完成的核心能力

### 后端

- 量表、题目、结果规则、版本管理
- 测评任务、草稿、提交、评分、报告
- 预警识别、认领、分派、干预、结案、复测任务
- 通知统一分发、设备登记、投递流水、失败重试、运维摘要
- 导出任务持久化、任务抢占、自动补跑、超时恢复、管理员重试
- 审计与会话可观测性基础能力

### Admin Web

- Dashboard、量表、任务、预警、报告、群体报告、预约、审计
- 通知中心基础管理
- 通知运维工作台：筛选、失败聚合、批量重试
- 导出中心：存储配置、最近任务、失败聚合、抽屉详情、重试与下载

### 用户侧 Web

- 我的任务
- 问卷作答与草稿恢复
- 我的报告
- 通知回流
- 预约创建

### Android 被测者端

- 登录、任务、答题、报告、预约、通知主链路
- 中、日、英三语界面与客户端校验
- Keystore 加密会话、自动刷新、FCM 设备注册、送达回执和通知业务跳转
- Android CI 单元测试与 Debug APK 构建任务

## 3. 当前仍未完成的项

### 明确未落地

- iOS 原生端
- 微信小程序
- Android 正式签名、生产 Firebase 参数和真机发布验证
- FCM 之外的更多真实 Push 厂商 SDK 直连
- 真实对象存储厂商 SDK 适配
- 刷新令牌黑名单
- 更完整的短期会话治理

### 已有第一版但仍需增强

- 设备风控的租户级 / 用户级策略覆盖
- 异常设备自动处置策略继续细化
- 导出多实例治理的可观测性
- 通知策略中心的审计、模板和更细粒度治理
- 常模批量导入与覆盖率校验
- `MATRIX` 等复杂题型的完整编辑和展示收口

## 4. 当前最值得继续做的剩余任务

1. 对象存储真实 SDK 适配
2. 设备风控与短期会话治理增强
3. 真实 Push 渠道接入

## 当前实现补充：认证自助注册
