## 5. 明确未完成项

- Android 原生端
- iOS 原生端
- 微信小程序
- 深度统计分析
- 完整 CI/CD 与自动化流水线
- 大文件场景下更完善的导出持久化方案

## 6. 当前主要风险

- 新增接口如果绕开国际化规范，容易再次出现中英混杂或硬编码文案。
- 导出链路虽然可用，但大文件和长期存储方案仍偏 baseline。
- 会话与鉴权主链路已经稳定，但产品级 UX 还有继续打磨空间。
- 多端尚未开始，后续推进前要先锁定 API 和权限边界。

## 7. 当前建议优先级

1. 收口用户体验：会话失效、重登、预约咨询细节。
2. 收口导出能力：PDF 字体、异步导出、文件存储策略。
3. 收口工程化：CI、自动化检查、部署与环境说明。
4. 再启动多端：Android、iOS、微信小程序。
